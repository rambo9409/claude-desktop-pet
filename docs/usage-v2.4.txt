原神启动 V2.4 — 双击加速冷却与甘雨蹬墙跳

启动与升级
解压后双击“原神启动.exe”。适用于 Windows 10/11，需 .NET Framework 4.8。
角色素材已经内嵌，无需 Python 或管理员权限。
先从旧版右键菜单退出，再启动新版。原有角色、移动模式、冷却、资讯布局和缓存继续使用。

本次更新
1. 珂洛（Claude 默认形象）的窗口能力保持5分钟冷却。每次双击珂洛减少1分钟剩余冷却，可以连续双击减至就绪；会显示剩余时间，并立即保存。
2. 单击仍为普通互动，拖拽不扣冷却。已经就绪时不积攒减免。双击只调整冷却，施法仍由正常行为触发；安静模式、隐藏和拖拽期间不自动施法。
3. 甘雨不再攀爬。她会在屏幕侧边与窗口侧边之间交替蹬跳上升，最后落在窗口顶部；相邻窗口之间也可以借力跳跃。每次碰壁短暂压腿，再反向蹬出。
4. 右键“蹬墙跳上附近窗口”可手动触发；自动移动开启且非安静模式时也会寻找路线。需要足够空间、可见墙面和可落脚的窗口顶部；没有合适路线时提示或折返。
5. 跳跃目标移动、消失、被遮挡，或路径失效时，甘雨会中止路线并展开风之翼缓降。拖拽、切换角色和调整大小会清理原路线。

基本操作
左键单击：对话。按住拖动：移动角色，可跨显示器。
双击珂洛：减少1分钟施法冷却。
右键：切换角色、移动模式、大小、安静模式，或打开“工具”。
鼠标滚轮、+ / -：调整大小。0：恢复默认大小。Esc：退出。
“立即跑步”：手动触发奔跑。胡桃显示为化蝶飞行；瓦雷莎有夜魂时为四倍超快跑。
“慢慢走一会儿”：普通慢速行走。

窗口魔法
珂洛会随机把普通应用窗口缩小至约65%尺寸，或拉到自己附近。
手心金色法阵、星光连线、目标窗口金边和前后位置虚线显示施法过程。
优先当前屏幕露出的窗口，跨屏目标会拉回身边。实际读取到尺寸或位置改变才提示成功。
成功冷却5分钟；目标无响应时15秒后重试。首次启动至少等待20秒，双击也可缩短这段等待。
起手后拖拽、切角色等主动中断保留已有冷却；双击中断后再扣减1分钟。
冷却跨角色切换和重启保存。重启仍有至少20秒启动等待。
排除桌面、任务栏、系统工具窗口、最小化和完全被遮挡的窗口及桌宠自身。
施法不会关闭窗口或抢走输入焦点；窗口仍可正常移动和调整大小。

角色能力
瓦雷莎夜魂按实际超快跑距离消耗，满条以当前屏幕从左下沿墙到顶部中间的路线校准。空条回满60秒，耗尽后需要完全恢复才能再次超快跑；半空耗尽会直接滑翔。
胡桃先人形跑动，再化为金蝶飞行；停下后恢复人形。
甘雨使用蹬墙跳；珂洛、胡桃和瓦雷莎保留原有攀爬行为。
胡桃、甘雨和瓦雷莎在拖拽、下落时展开对应颜色的风之翼并缓慢下降。

GPT重置预测
右键 → 工具 → GPT重置预测。
同步 https://tangyun.ai/ 的公开预测，接口注明的上游为 https://codex-reset.com/ 。
显示24/48小时概率、上次重置、历史常见时段、间隔图和历史记录，每10分钟自动刷新。
第三方全站重置观察与个人账号额度重置不同，概率不保证发生，历史时段也不是下次重置时间。
统一使用北京时间UTC+8。明确提供截止时间和信号时才显示倒计时。
网络失败保留快照，来源失效或超过20分钟未更新时标记为过期。

设置与缓存
保存于 %LocalAppData%\KoloPet，升级无需删除。
资讯和预测只访问公开接口，无需登录；不读取浏览器Cookie或密码，不上传个人文件。
