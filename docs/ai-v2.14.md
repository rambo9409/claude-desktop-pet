# V2.14 连续点击主动换装修复

2026-11-05，程序集2.14.0.0。只修正珂洛主动换装的输入处理，保留V2.13跑步素材及自动三分钟规则。

## 问题与行为

V2.13在第8次有效点击后已经发出手动换装请求，但`OnPointerDown`把每次后续按下都当作新抓取，直接取消请求及动画。换装需要4.8秒，用户继续第9下就会中断，看起来像始终没有触发。原测试停在第8下，未覆盖继续连点。

连续四组双击仍使用Windows双击规则，组间完成时间不超过1.5秒；触发前本子操作不计数。前3组显示1/4、2/4、3/4进度，前4组各减1分钟窗口魔法冷却，最低归零。地面有支撑时第8次松手立即显示第一张换装帧，空中或门户中保留请求，落稳再播放。

手动请求已发出后，普通后续点按受到保护，包括动画正在播放和等待安全落地两种状态。它们不取消请求、不重新开门户、不切回开心姿态，也不重复扣冷却。本子预览事件在这段时间转交身体的保护逻辑，避免第8下刚触发、下一帧之前命中旧本子画面而取消。

按住并真正拖动超过5px时，才解除保护、取消手动请求并进入原有拖拽路径。打开菜单、隐藏、最小化、切换角色等明确操作仍会清理手动请求及保护状态。取消手动请求不清除已经满足的自动180秒资格；自动规则本身不变。

## 接手要点

- `PetMovement.cs`负责按下、移动、松开期间的续点保护与真实拖拽转换。不要仅跳过`CancelKoloEasterEgg()`后继续设置`pointerHeld`，否则下一帧的安全条件仍会取消演出。
- `PetNotebook.cs`的预览命中优先于身体事件，必须与手动保护协调。
- `PetKoloEasterEgg.cs`保留统一4.8秒换装和正式角色切换路径，开始时立即出帧。
- 回归需要包含8次后继续点9–12次、等待门户期间续点、真实拖拽取消，以及隐藏/最小化/切换和丢失捕获的清理。不能只断言第8下后`Active`为真。
