珂洛桌宠 V2.0 — 展翼滑翔

启动
解压后双击“珂洛桌宠.exe”。适用于 Windows 10/11，需 .NET Framework 4.8。
角色图片已内嵌，无需安装 Python、无需管理员权限。
升级时先从旧版右键菜单退出，再启动新版。原有角色、大小、移动模式及看点布局设置会保留。

V2.0 更新
1. 胡桃、甘雨和瓦雷莎各增加八帧展翼滑翔动作：抬臂展翼、屈腿滑翔、收翼、缓冲落地。
2. 左右风之翼围绕肩部展开，与身体朝向、倾斜和缩放同步。胡桃为黑红暗金、甘雨为蓝白、瓦雷莎为紫粉。
3. 按住拖动时展开，松手下落时继续滑翔，不重复展开。落地收翼；互动和切换动作可直接打断。默认角色珂洛沿用原有姿态。
4. 保留胡桃人形奔跑后逐渐蝶化、甘雨贴地慢走及快速攀爬/窗口跳跃、瓦雷莎面具风火轮奔跑。
5. 合并上下攀爬的重复图片与资源读取代码，统一构建和测试流程；旧文件归档，发布包只包含程序及本说明。

操作
左键单击：对话。左键按住拖动：移动角色，可跨显示器。
右键：打开菜单，切换角色、互动、移动模式、大小，或打开今日看点。
鼠标滚轮、+ / -：调整大小。0：恢复默认大小。Esc：退出。
菜单“动作与大小”可手动慢走或奔跑；胡桃显示为化蝶飞行。
甘雨有“跳到附近窗口”；需要附近存在合适的可见窗口边缘。
安静模式减少自动活动；自动移动关闭后仍可手动触发动作。

今日看点
包含微博热搜、B站热门、体育及虎扑 NBA。
点击版块标题折叠/展开，拖动标题旁的手柄调整顺序；布局自动保存。
联网后可更新，内容与源网站可用性有关。

设置与缓存
保存于 %LocalAppData%\KoloPet。升级无需删除该目录。
本程序的角色形象为同人 Q 版桌宠素材。
