# V2.11 珂洛传送、慢走与换装彩蛋

本版处理珂洛的拖拽松手演出和慢走动作，并加入待机变为现有DeepSeek蓝发鱼尾女仆的彩蛋。

## 空中传送

把珂洛拖到空中后松手，她会减速稳住，脚下打开黑色椭圆传送门，身体从门中进入，再在当前显示器的桌面底部出现并收门。全程约2.95秒。门口的裁剪平面和身体位移由WPF绘制，保留人物原有身形。

触发点仅在拖拽松手时。距当前屏底很近时直接落地，放手速度会限制。走出窗口边缘等自然掉落沿用原来的下落逻辑。传送中重新抓取会取消当前演出，隐藏、最小化、切换和关闭也会恢复人物可见性，避免留下透明角色或门户。

目标位置使用当前显示器工作区，包含副屏、负坐标和显示器布局变化。传送中缩放或屏幕消失时会重新限制落点。持本和空手都能传送，期间暂停窗口魔法。按住手中本子时暂停传送计时和角色位移；即使把本子拖离，松手后才继续，避免角色从鼠标下移走。再次抓住角色则取消传送。验证覆盖范围以本版验证记录为准，不将模拟布局写成物理双屏实测。

## 慢走

空手和持本慢走各提供4个重新绘制的姿态，使用统一画布、身体比例和接地位置。持本慢走的4个交互矩形随新图重新测量。继续按走过的距离推进动作相位，避免改变移动速度时脚步节奏失配。

## 待机换装

彩蛋全程保持完整衣着，通过摘换发饰和不透明布料遮挡完成换装。共8个运行帧，总时长4.8秒，最后成为正式DeepSeek角色。末帧使用正式DeepSeek待机图，随后调用既有角色切换流程，更新菜单、工具头像、专属能力和已选角色存档。

“待机换装彩蛋”默认开启，可在珂洛右键菜单关闭，安静模式中暂停。启动后有5分钟冷却，连续待机至少12秒后每30秒抽签一次，概率12%。触发后再次冷却5分钟，手动切回或中断后有至少45秒宽限。抽签不随帧率增加，也不会在电脑唤醒后补抽过去的次数。

仅在珂洛可见、没有最小化、处于有真实支撑的待机状态时触发。普通移动、鼠标拖拽、本子拖拽、菜单展开、窗口魔法和传送均会阻止或取消彩蛋。开启彩蛋的非安静珂洛采用16–28秒自动待机间隔，让12秒的连续闲置条件可达。其他角色沿用原有移动间隔。

开始演出时自动归还小本本，关闭独立本子窗口。换装帧在持本绘制之后应用，避免本子姿态把演出覆盖。再次抓取、放大、缩小、恢复默认大小、手动切角色、失去支撑、隐藏、最小化、开启安静模式、关闭彩蛋或退出会取消，并恢复当前角色正常姿态。取消后不会在原定结束时间再次切换角色。完成后可从“选择形象”切回珂洛。

## 维护

- `src/PetKoloPortal.cs` 管理传送阶段、减速、落点和WPF门口绘制，`PetMovement.cs`在拖拽松手时启动并更新。
- `src/PetKoloEasterEgg.cs` 管理可测试的概率计时、资格检查、8帧演出和正式角色切换。开关通过 `PetStorage` 原子写入 `%LocalAppData%/KoloPet/kolo-easter-egg-enabled.txt`。
- `ClaudePetMotion.cs` 负责逐帧接入、取消和帧选择顺序。窗口魔法必须在目标枚举前检查两种演出状态。
- `build_kolo_v211.py`、`kolo-stroll-v211.png`、`kolo-disguise-v211.png`、裁切配方与 `kolo-v211-prompts.md` 构成素材来源。美术通过内置imagegen生成，打包只裁切、等比缩放与定位。

`build_assets.py --refresh-v211` 更新8张慢走图和命中框JSON中的4项，新增8张换装图。包内208项由207张PNG和1份JSON构成，其他191个旧条目须与V2.10逐字节一致。第8张换装帧复用DeepSeek正式待机图，前7张来自生成的换装图集。

新增 `KoloPortal` 与 `KoloEasterEgg` 测试，22组默认回归加VisualSmoke共23组。最终测试、资源比较、启动与发布结果写入 [V2.11验证记录](validation-v2.11.md)。
