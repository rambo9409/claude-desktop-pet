原神启动 V2.9 — 鲸尾少女与珂洛的小本本

启动与升级
退出旧版，解压后运行“原神启动.exe”。适用于 Windows 10/11 + .NET Framework 4.8。
运行无需Python、Windows SDK或管理员权限。角色、移动设置、冷却和资讯缓存继续使用。

参考形象与可拖本子
DeepSeek小肥鱼现在是参考图中的蓝发鲸尾女仆少女，保留灵感泡泡。
珂洛默认拿着本子，持本时不会缩小或拉动其他窗口。
按住她手里的本子向外拖，松手后本子可独立移动；点击不是拖走，也不会扣施法冷却。
拖离后仍遵守窗口魔法开关、五分钟冷却和安静模式，不自动开启关闭的能力。
把本子拖回珂洛身上、双击桌面本子，或通过右键归还，即可立即暂停施法。
隐藏、最小化、切换形象、退出和重启都会回收本子，避免物件遗失。
详细说明：docs/notebook-v2.9.md。

AI伙伴
右键 → 角色可切换GPT6A·龙女、DeepSeek·小肥鱼，原四位角色保留。
龙女：双击开始25分钟龙息专注；右键可选15/25/45分钟、查看剩余或取消。
星环显示进度，到时提醒；隐藏、切换角色或退出会取消计时，不修改其他应用窗口。
小肥鱼：双击打开灵感泡泡，输入文字后点击保存，支持回看、编辑和删除。
灵感本只保存在本机，不读取账号或剪贴板；切换角色暂时收起窗口，未保存草稿仍留在本次运行内。
这两项能力不接入AI模型，无需API密钥。详细说明：docs/ai-companions-v2.8.md。

先选拥有角色，再找配队
角色右键 → 工具 → 战斗循环助手。
1. 打开“我的角色”，搜索并勾选拥有的角色后保存。旅行者的各元素形态分别选择。
2. 找不到新角色时可手动添加名字；已导入配队里的新成员也会补入可选名单。
3. 按已拥有角色筛选，只有四人齐全的队伍才作为可用攻略。缺员视图会说明缺少谁，不会直接载入缺员队。
4. 选择队伍查看来源、适用版本、核对日期、命座/武器条件、输出手法及充能建议，再载入四名成员。
5. 匹配仅限已收录的攻略。没有匹配不代表角色不能组队，也不会自动替换角色后套用旧手法。

面板与截图
1. 推荐队伍的数字是通用输入示例，不是实测面板或天赋倍率，请替换成自己的数据。
2. 选中角色页，手动输入，或点击“从截图识别”/“粘贴截图识别”。使用清晰的详细属性截图。
3. OCR在本机运行，不上传截图；先核对预览，可修改和取消勾选，再应用。未识别字段保持原值。
4. 角色名、技能倍率和技能时间需要手动填写；识别不支持时仍可一直手动输入。
5. 生成后查看手法、循环时长与通用参考线。只有模型支持的队伍才显示当前/达标后伤害及每秒伤害。
6. 错误字段会标红并集中列出；重要存档原子保存，损坏文件先备份。

窗口魔法与其他操作
珂洛右键可独立开关窗口魔法；新安装默认关闭，已使用旧能力的升级用户保留启用状态。
每次成功施法冷却5分钟；双击珂洛缩短1分钟，最低归零；双击不会自动开启能力。
单击对话；拖动可跨屏；滚轮或+/-改变大小；0恢复默认；Esc退出。
