珂洛桌宠 V2.1 — 角色主题热点与无重力跑墙

启动
解压后双击“珂洛桌宠.exe”。适用于 Windows 10/11，需 .NET Framework 4.8。
角色图片已内嵌，无需 Python，无需管理员权限。
升级时先从旧版右键菜单退出，再启动新版。原有设置与看点版块布局继续使用。

V2.1 更新
1. 今日看点全新角色主题界面：头像标题栏、今日速览、分区排行卡片、统一按钮及滚动条。珂洛橙金、胡桃黑红、甘雨蓝白、瓦雷莎紫粉，随角色实时切换。
2. 瓦雷莎奔跑速度再次翻倍，为普通角色的四倍，默认大小下约380–560像素/秒。奔跑可直接上墙，沿屏幕顶部倒挂前进，保持面具与风火轮跑姿，连贯经过转角。
3. 移除所有角色右键菜单的互动分区，包括摸摸她、让她开心、送她玫瑰、陪我工作。
4. 保留原有左键对话、慢走、胡桃跑步蝶化、甘雨蹬壁跳跃，以及三位原神角色拖拽/下落时的展翼滑翔动画。

操作
左键单击：对话。左键按住拖动：移动角色，可跨显示器。
右键：切换角色、移动模式、调整大小、设置安静模式或打开今日看点。
右键“立即跑步”：手动触发瓦雷莎高速奔跑；胡桃显示为化蝶飞行。
右键“慢慢走一会儿”：普通慢速行走。
鼠标滚轮、+ / -：调整大小。0：恢复默认大小。Esc：退出。
自动移动关闭后仍可手动触发移动；安静模式减少自动活动。

今日看点
包含微博热搜、B站热门、体育和虎扑NBA。
点击版块标题折叠/展开，拖动标题旁的手柄上下排序，布局自动保存。
联网后可更新；源站暂时不可用时会显示状态。

设置与缓存
保存于 %LocalAppData%\KoloPet，升级无需删除。
本程序的角色形象为同人Q版桌宠素材。
