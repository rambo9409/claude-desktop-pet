原神启动 V2.6 — 战斗循环助手与截图面板导入

启动与升级
退出旧版，解压后运行“原神启动.exe”。适用于 Windows 10/11 + .NET Framework 4.8。
运行无需Python、Windows SDK或管理员权限。角色、移动设置、冷却和资讯缓存继续使用。

战斗循环助手
角色右键 → 工具 → 战斗循环助手。
1. 可选择推荐配队查看手法、充能建议、适用版本和来源。点击“载入成员”填入四人队。
2. 推荐队伍的数字是通用输入示例，不是实测角色面板或天赋倍率。请自行替换。
3. 选中角色页，手动输入，或点击“从截图识别”/“粘贴截图识别”。使用清晰的角色详细属性截图。
4. OCR在本机运行，不上传截图；先核对预览，可修改和取消勾选，再应用。未识别字段保持原值。
5. 攻击/生命/防御按所选伤害基值填入；双暴、充能和对应元素加成可导入。角色名、技能倍率、技能时间需要手动填写。
6. 点击生成，查看一般顺序、循环时长、当前与达标后每秒、通用参考线；错误字段标红并集中列出。
7. 保存使用临时文件原子替换。损坏存档先备份；备份失败则拒绝覆盖，错误信息可在diagnostics.log查阅。

配队资料截至2026-10-29，按已上线7.1核验；当前提供10套有来源的参考队伍，不是深渊强度排名或最佳配装保证。
循环手法来自攻略或已明确标注的简化建议。需要命座/武器的条件在卡片内说明。
通用公式没有逐击附着、快照、精通缩放或特殊资源模拟。无法支持的配队只显示攻略手法，不显示伤害估算。
建议面板是按职责设置的通用参考线，不是具体角色毕业标准。精确模拟可打开来源文档里的gcsim/Genshin Optimizer。
系统若缺少OCR语言包，按提示安装简体中文OCR，也可以一直使用手动输入。

窗口魔法
珂洛右键可独立开关“窗口魔法（缩小或拉近窗口）”。新安装默认关闭；已用旧版能力的升级用户保留启用状态。
关闭立即中止施法。每次成功施法冷却5分钟；双击珂洛缩短1分钟，最低归零，双击不会自动打开开关。

其他操作
单击对话；拖动可跨屏；滚轮或+/-改变大小；0恢复默认；Esc退出。
甘雨可双屏借力、单墙连续蹬跳并先靠近起跳点；瓦雷莎保留夜魂高速跑墙；胡桃保留奔跑化蝶。
工具中的每日看点可折叠和拖动分区排序；GPT重置预测同步第三方公开全站数据，不代表个人额度。

设置目录：%LocalAppData%\KoloPet。
工程说明：README.md；交接：docs/HANDOFF.md；配队来源：docs/combat-data-sources.md。
助手不读游戏内存、不自动按键或执行战斗操作。角色为同人Q版素材。
