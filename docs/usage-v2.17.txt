原神启动 V2.17 — 角色字幕与移动跟随

启动与升级
退出旧版，解压后运行“原神启动.exe”。适用于 Windows 10/11 + .NET Framework 4.8。
运行无需Python、Windows SDK或管理员权限。角色、移动设置、冷却和资讯缓存继续使用。

本版变更
六个角色使用各自的字幕气泡：珂洛橙米手账、龙女银紫星纹、小肥鱼蓝白泡泡、胡桃黑红梅花、甘雨蓝白冰晶、瓦雷莎紫粉能量。
正文约16px。字幕随角色移动、拖拽、缩放和跨屏调整位置；靠近屏幕边缘会让位并保持在工作区内。
同一角色的动作帧不会带着字幕上下抖动。字幕不会抢焦点，也不会挡住鼠标点击。详细说明见源码 docs/speech-v2.17.md。
珂洛换装继续使用约3.2秒的加速节奏，自动三分钟和主动四组双击规则不变。
GPT重置预测已在V2.15移除；旧预测缓存不再读取或刷新。

连续四组双击主动换装
在珂洛的头部或身体连续双击4组，共8次有效点击；每组遵守Windows双击规则，相邻两组的完成时间间隔不超过1.5秒。
四次单击不会触发。不要点到手里的小本本，本子点击和拖动有独立用途，不计入手势。
前3组双击显示1/4、2/4、3/4进度；前4组每组仍减少1分钟窗口魔法冷却，最低归零。第4组额外主动请求换装成DeepSeek，不必等三分钟。
即使右键自动彩蛋开关关闭，主动手势仍可使用，且不改变开关。人物落稳时第8次松手立即显示换装第一帧，空中或传送中则等到安全支撑后开始；演出约3.2秒。
手动请求已经触发后，继续普通点击不会取消演出或待播放请求，也不再重复扣冷却。此时点在本子区域也受同样保护，等待换装完成后再操作。
触发前，拖拽、超时、多余不成对单击、本子操作及跨角色会清空计数。触发后，按住并真正拖动超过5px才按拖拽取消；打开菜单、隐藏、最小化、切换角色等明确操作仍会取消手动请求。
手动演出中断后不会自己重试，但已经满足的自动三分钟资格仍按下方规则保留。

珂洛只慢走
珂洛的跑步入口已移除，自动移动和原有跑步调用都使用慢走，持本与空手继续采用交替步态。
其他角色保留跑步。珂洛的拖拽传送保留：空中松手先减速稳住，再打开脚下黑色传送门，约3秒后回到当前显示器底部。
靠近屏幕底部松手时直接落地。自然走出窗口边缘的掉落不会自动开传送门。
传送中再次抓住她可中断；已有手动换装请求时，普通续点受保护，真正拖动才中断。隐藏、切换形象、退出会清理演出。
普通传送中按住手里的小本本会暂停；松手后继续，包括把本子拖离后松手。已有手动换装请求时，本子区域普通续点不会打断。

自动三分钟换装DeepSeek
右键“待机换装彩蛋”默认开启。选中珂洛累计可见使用3分钟后，必定播放换装彩蛋，变成现有的DeepSeek形象。
移动和安静模式也计时，不需要连续待机，也不再随机抽签。隐藏、最小化会暂停；切换角色或重新开启彩蛋后重新计时。
到期时若正拖拽角色、本子、使用菜单、传送或施法，会保留到期资格，等当前动作安全结束并有支撑后开始。普通移动会停下再换装。
演出约3.2秒，摘换发饰并用不透明布料遮挡换装，开始时自动收回小本本。期间仍可拖拽或缩放中断；中断后到期资格保留，会在安全时机继续触发。
关闭自动彩蛋或手动切换角色可以阻止自动补触发；主动四组双击独立于开关。完成后就是正常的DeepSeek，菜单和专属功能一同切换；可通过“选择形象”切回珂洛，开始新的3分钟。
进度不跨程序重启保存；休眠或长时间UI阻塞不计入使用时长。详细规则见源码 docs/ai-v2.12.md。

小肥鱼记事窗
双击DeepSeek打开“灵感泡泡”，输入文字后点击保存，支持回看、编辑和删除，最多100条、每条2000字。
窗口采用与其他工具一致的DeepSeek浅蓝主题：圆角外框、渐变标题、卡片、输入框、历史选中态、按钮与滚动条。
拖动标题可以移动窗口，右上角可最小化或关闭，窗口可调整大小。未保存修改仍会在新建、切换历史和关闭时提示确认。
灵感只保存在本机，不读取账号或剪贴板，也不发送给模型；切换角色会暂时收起窗口，未保存草稿保留在本次运行内。

GPT6A龙女统一画风
右键 → 选择形象 → GPT6A·龙女。
保留白银长发、浅紫眼睛、龙角、蝠翼、卷尾和白紫裙装，头身比例、线条、发束和分层上色统一到珂洛及DeepSeek的画风。
V2.12统一了待机、表情、移动、攀爬、施法和空中动作的画风；V2.13进一步修正跑步四帧，菜单与专注星环仍使用紫白配色。
双击开始25分钟龙息专注；右键可选15、25或45分钟，也可查看剩余或取消。星环显示进度，到时提醒。
隐藏、切换形象或退出时取消计时，不修改其他应用窗口。这项能力与小肥鱼灵感本不接入AI模型，无需API密钥。
详细说明见源码 docs/ai-v2.12.md；历史能力介绍见 docs/ai-companions-v2.8.md。

可拖小本本
珂洛默认拿着本子，持本时不会缩小或拉动其他窗口。
按住她手里的本子向外拖，松手后本子可独立移动；点击不是拖走，也不会扣施法冷却。
拖离后仍遵守窗口魔法开关、五分钟冷却和安静模式，不自动开启关闭的能力。
把本子拖回珂洛身上、双击桌面本子，或通过右键归还，即可立即暂停施法。
隐藏、最小化、切换形象、退出和重启都会回收本子，避免物件遗失。
详细说明：docs/notebook-v2.9.md。

先选拥有角色，再找配队
角色右键 → 工具 → 战斗循环助手。
1. 打开“我的角色”，搜索并勾选拥有的角色后保存。旅行者的各元素形态分别选择。
2. 找不到新角色时可手动添加名字；已导入配队里的新成员也会补入可选名单。
3. 按已拥有角色筛选，只有四人齐全的队伍才作为可用攻略。缺员视图会说明缺少谁，不会直接载入缺员队。
4. 选择队伍查看来源、适用版本、核对日期、命座/武器条件、输出手法及充能建议，再载入四名成员。
5. 匹配仅限已收录的攻略。没有匹配不代表角色不能组队，也不会自动替换角色后套用旧手法。

面板与截图
1. 推荐队伍的数字是通用输入示例，不是实测面板或天赋倍率，请替换成自己的数据。
2. 选中角色页，手动输入，或点击“从截图识别”/“粘贴截图识别”。使用清晰的详细属性截图。
3. OCR在本机运行，不上传截图；先核对预览，可修改和取消勾选，再应用。未识别字段保持原值。
4. 角色名、技能倍率和技能时间需要手动填写；识别不支持时仍可一直手动输入。
5. 生成后查看手法、循环时长与通用参考线。只有模型支持的队伍才显示当前/达标后伤害及每秒伤害。
6. 错误字段会标红并集中列出；重要存档原子保存，损坏文件先备份。

通用公式未逐击模拟附着、快照、精通反应、特殊资源与装备命座。参考属性线不是角色毕业标准。

窗口魔法与其他操作
珂洛右键可独立开关窗口魔法；新安装默认关闭，已使用旧能力的升级用户保留启用状态。
每次成功施法冷却5分钟；双击珂洛缩短1分钟，最低归零；双击不会自动开启能力。
单击对话；拖动可跨屏；滚轮或+/-改变大小；0恢复默认；Esc退出。
甘雨保留双屏蹬墙跳，瓦雷莎保留夜魂高速跑墙，胡桃保留奔跑化蝶，三位原神角色保留滑翔翼。
每日看点可折叠和拖动分区排序，布局会自动保存。
