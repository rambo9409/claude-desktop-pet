# V2.1 发布验证

验证日期：2026-10-26。程序集与文件版本均为 **2.1.0.0**。

## 本次更新

- 今日看点使用与右键菜单共用的角色配色，新增缓存头像、今日速览、来源分区和排行卡片，并统一按钮、滚动条、加载和错误状态。切换角色直接更新动态主题资源，保留滚动、折叠、排序与刷新状态。
- 瓦雷莎奔跑速度为普通角色四倍，即 V2.0 的两倍，默认大小下 380–560 像素/秒。使用面具风火轮跑姿沿屏幕左右墙及顶边连续移动，也能接上窗口侧边。转角按路程推进并保留本帧剩余时间；同一组图像边界保证旋转时不逐帧缩放抖动。
- 删除四个角色右键菜单的互动分区及四项操作。保留左键对话。
- 跑墙时切换慢走、角色、大小，或抓取角色，均退出当前路径；窗口消失、移动或屏幕变化时安全脱离。路径空间不足时掉头或下落，不切回普通攀爬。
