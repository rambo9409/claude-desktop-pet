原神启动 V2.3 — 窗口魔法、每日看点与 GPT 重置预测

启动与升级
解压后双击“原神启动.exe”。适用于 Windows 10/11，需 .NET Framework 4.8。
角色素材已经内嵌，无需 Python 或管理员权限。
软件原名“珂洛桌宠”；升级时先从旧版右键菜单退出，再启动新版。角色、移动模式、冷却和资讯布局设置继续使用。

V2.3 更新
1. 珂洛举手后出现旋转金色法阵、星光和牵引线。目标窗口带金色描边，虚线标出变化前后的位置，缩小或拉近的过程更清楚。
2. 优先选择当前屏幕露出的窗口；跨屏目标会拉到身边。只有读取到真实尺寸或位置变化才算成功，成功冷却5分钟；目标拒绝移动时提示失败，15秒后重试。
3. 每日看点新增 GitHub 热门 Fork、AI、股票、汽车、游戏和美女·时尚，总共10个版块。固定分类导航可直接跳转，每栏显示来源、更新时间和缓存状态。
4. 工具新增 GPT 重置预测，同步 tangyun.ai 公开数据，显示24/48小时概率、上次重置、历史常见时段、间隔图和历史记录。每10分钟自动刷新，支持手动刷新，沿用角色配色。
5. 软件和发布包正式命名为“原神启动”。

操作
左键单击：对话。按住角色拖动：移动，可跨显示器。
右键：切换角色、移动模式、大小、安静模式，或进入“工具”下的每日看点和 GPT 重置预测。
鼠标滚轮、+ / -：调整大小。0：恢复默认大小。Esc：退出。
“立即跑步”：手动触发奔跑。胡桃为化蝶飞行；瓦雷莎有夜魂时为四倍超快跑。
“慢慢走一会儿”：普通慢速行走。
安静模式减少自动活动并暂停珂洛自动施法。

窗口魔法
珂洛（Claude 默认形象）会随机把一个普通应用窗口缩小至约65%尺寸，或拉到自己附近。
首次施法前等待20秒；拖拽、隐藏和安静模式期间不自动施法。冷却跨角色切换和重启保存。
起手后主动拖拽、切换角色等中断操作保留5分钟冷却，避免连续触发。
排除桌面、任务栏、系统工具窗口、最小化窗口、完全被遮挡的窗口和桌宠自身。
窗口仍可正常移动、调整大小；施法不会关闭窗口或抢走输入焦点。
没有合适目标时稍后再试。

每日看点
包含微博、B站、体育、虎扑NBA、GitHub、AI、股票、汽车、游戏和美女·时尚。
GitHub 展示近90天创建的公开原创项目，按累计 Fork 排序，附 Star 数和语言。
美女·时尚包括女星、时尚、写真相关资讯。
点击顶部分类跳转；点击版块标题折叠/展开，拖动标题旁手柄上下排序。布局自动保存。
后台每6小时检查更新，复用当天3小时内的结果；打开窗口后可手动刷新。
每栏独立显示来源与时间；连接失败时使用该栏最近7天内的缓存，并标明状态。

GPT 重置预测
入口：右键 → 工具 → GPT 重置预测。
同步来源：https://tangyun.ai/ ，接口注明的上游来源为 https://codex-reset.com/ 。
这是第三方全站重置观察，与个人账号额度重置不同，本工具不读取个人账号额度。
概率来自站点模型，并不保证发生。历史常见时段不是下一次重置时间。
时间统一使用北京时间 UTC+8。源站提供明确时间和信号时才显示倒计时；未提供时会提示。
每10分钟刷新；网络失败保留上次快照，来源失效或超过20分钟未更新时标记为过期。
“原站”按钮可打开来源页面查看。

原有能力
瓦雷莎夜魂按实际奔跑距离消耗，满条按当前屏幕从左下沿墙到顶部中间的路线校准；耗尽后需要完全恢复才能超快跑，空条回满60秒，半空耗尽会展翼滑翔。
胡桃跑动中化为金蝶；甘雨可快速攀爬和跳到附近窗口。三位原神角色拖拽、下落时展开对应颜色的风之翼并缓慢下降。
珂洛保持橙色长发、金花、黑色蝴蝶结、米白裙和黑色束腰造型。

设置与缓存
保存于 %LocalAppData%\KoloPet，升级无需删除。
资讯与预测仅访问公开接口，无需登录；应用不读取浏览器Cookie或密码，不上传个人文件。
本程序的角色形象为同人Q版桌宠素材。
