# V2.10 白银淡紫龙女

GPT6A·龙女按用户最新参考重绘为白银长发、浅紫眼睛、两只短龙角、浅紫蝠翼、卷曲龙尾和白紫裙装的Q版少女。参考图中的大头比例、圆脸、花结发饰和低饱和配色是造型依据。参考保存在 `assets/source/gpt6a-reference-v210.png`。

## 使用

右键选择 `GPT6A·龙女` 即可使用新版形象。旧版已选中龙女的用户升级后会直接显示新素材。待机、表情、慢走、奔跑、攀爬、施法、拖拽和下落都使用同一套造型，菜单采用紫白色，专注星环为淡紫色，计时牌为深紫底白字。

双击龙女开始25分钟龙息专注，右键菜单可选15、25或45分钟，查看剩余时间或取消。隐藏、切换角色和退出会取消当前计时。它在本机运行，无需模型API或账号。

## 素材与维护

通过内置imagegen按参考生成透明素材，完整提示词与生成记录保存在 `assets/generated/gpt6a-v210-prompts.md`。`build_gpt6a_v210.py` 负责图集裁切、等比缩放及运行画布定位，`build_assets.py` 统一打包。源图、裁切配方、预览应一并保留，方便下一位开发者核对。

龙女的运行键保持 `gpt6a`，共27张PNG，沿用既有动作键。只刷新龙女可执行 `build_assets.py --refresh-v210`。其余173项资源，包括珂洛持本命中框，应与刷新前逐字节一致。完整重建仍通过 `build.cmd -RebuildAssets`，检查帧数、透明边界、身体尺寸以及翅膀与尾巴是否切断。

菜单与工具主题入口为 `MenuPalette.ForCharacter("gpt6a")`。专注星环和计时牌颜色在 `src/PetAiAbilities.cs`。颜色调整不应改变 `DragonFocusSession` 的UTC截止时间或隐藏、切换时取消的规则。
