# V2.9 参考形象与珂洛的小本本

用户提供了两张参考图：DeepSeek是蓝发鲸尾女仆少女；Claude/珂洛是橙发、金花与黑缎带、白色褶边服装及黑束腰的形象，手中拿着小本本。不要继续把“小肥鱼”理解为只有鳍和尾巴的动物鲸鱼。参考图保存在 `assets/source/deepseek-reference-v29.png` 和 `kolo-reference-v29.png`。

## 使用

珂洛启动时默认拿着本子。手中有本子时，窗口魔法被阻止，不能缩小或牵引其他窗口。点击本子与拖动整个角色分别处理；将本子从手中拖离后，它成为可以独立移动的桌面小物件。

离手只恢复窗口魔法资格，仍需原有开关已开启、冷却结束，并满足非安静模式、非拖拽等条件。拖走本子不强行开启用户关闭的窗口魔法，也不清零五分钟冷却。

将本子拖回角色，或使用归还操作，可以让珂洛重新拿住；归还立即中止正在进行的施法。切换形象、隐藏和退出会回收本子；重启默认持本，避免忘在另一屏而继续捣乱。

小肥鱼保留灵感泡泡的本地随手记，外观和动作改为参考中的鲸尾少女。GPT6A、胡桃、甘雨和瓦雷莎的形象与专属功能保持原样。

## 维护

本子状态、命中检测、拖拽与独立窗口在 `src/PetNotebook.cs`，窗口魔法资格在 `PetWindowAbility.cs`，最终持本帧选择与输入钩子在角色窗口和移动模块。命中区域需要跟随实际图像的缩放、镜像和坐标变换，不能直接把512素材坐标当成桌面坐标。

绘制了本子的姿态和空手姿态是两组素材。离手后必须切换空手组，不能只把一个透明按钮移走却保留画面中的本子。持本时不应出现空手施法帧。

素材通过内置imagegen生成，原图、提示词和裁切参数保存在 `assets/generated/`，打包仅裁切、等比缩放及定位。`build_deepseek_v29.py`、`build_kolo_v29.py` 为两角色的素材打包模块，主入口仍是 `build_assets.py`。

验证与发布结果见 [V2.9验证记录](validation-v2.9.md)。涉及原生窗口的测试只操作自建测试窗口；本子自身属于本进程，必须排除在窗口魔法目标外。
