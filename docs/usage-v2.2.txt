珂洛桌宠 V2.2 — 夜魂跑墙、轻盈滑翔与窗口魔法

启动
解压后双击“珂洛桌宠.exe”。适用于 Windows 10/11，需 .NET Framework 4.8。
角色图片已内嵌，无需 Python，无需管理员权限。
升级时先从旧版右键菜单退出，再启动新版。原有设置与看点版块布局继续使用。

V2.2 更新
1. 珂洛（Claude 默认形象）采用新造型：橙色长发、金花、黑色蝴蝶结、米白裙与黑色束腰。待机、慢走、跑步、攀爬和举手施法保持同一造型。
2. 瓦雷莎新增夜魂条。满条可沿当前屏幕从左下跑上左墙，到达顶部中间；夜魂按实际跑过的距离消耗，显示器及角色大小会影响路径校准。
3. 夜魂耗尽后，超快跑暂停，仍可普通走路和跑步。离开超快跑时逐渐恢复，空条完全恢复需要60秒；耗尽后必须回满才能再次超快跑。半空中耗尽会直接展翼滑翔。
4. 胡桃、甘雨、瓦雷莎的滑翔改成缓慢下降，默认大小稳定下降约88逻辑像素/秒；甩出时减速，落到窗口或地面后收翼。
5. 珂洛新增举手操控窗口能力：短暂举手后，随机缩小一个打开窗口的尺寸，或将它拉到身边。首次可用前有20秒等待，每次举手施法冷却5分钟。拖拽、隐藏、安静模式期间不自动施法；切换角色和重启不清空冷却。

操作
左键单击：对话。左键按住拖动：移动角色，可跨显示器。
右键：切换角色、移动模式、调整大小、设置安静模式或打开今日看点。
右键“立即跑步”：手动触发奔跑。胡桃显示为化蝶飞行；瓦雷莎有夜魂时为四倍超快跑，无夜魂时为普通跑步。
右键“慢慢走一会儿”：普通慢速行走。
鼠标滚轮、+ / -：调整大小。0：恢复默认大小。Esc：退出。
自动移动关闭后仍可手动触发移动；安静模式减少自动活动并暂停珂洛自动施法。

窗口魔法
只选择可见、未最小化的普通应用窗口，排除桌面、任务栏、系统工具窗口和桌宠自身。
“缩小”会缩小窗口尺寸，保留标题栏；“拉近”会将窗口移至珂洛所在屏幕内。窗口仍可由你正常移动和调整大小。
施法不会关闭窗口或抢走输入焦点。没有合适窗口时稍后再试。

今日看点
包含微博热搜、B站热门、体育和虎扑NBA。界面随角色切换配色。
点击版块标题折叠/展开，拖动标题旁的手柄上下排序，布局自动保存。
联网后可更新；源站暂时不可用时会显示状态。

设置与缓存
保存于 %LocalAppData%\KoloPet，升级无需删除。
本程序的角色形象为同人Q版桌宠素材。
