- `assets/` 根目录的 25 张早期独立动作帧归档。现行素材构建读取源图和图集，运行时使用内嵌 `characters.zip`，不读取这些散落帧。
- 将 7 个旧检查产物（检查 EXE/DLL/RSP、虎扑网页快照）归档。
- 历史测试 EXE、RSP、日志、PNG、GIF、208 张分帧图归档；测试源目录只保留 C# 与 PS1。
- Python 编译缓存归档。
- 三张未被构建引用的甘雨慢走历史源图 `ganyu-stroll-v15/v16/v17.png` 归档到 `archive/source-history/ganyu-stroll/`，共 3,993,519 字节；对应历史提示词增加新位置说明。

以上共归档 **280 个文件、243,907,838 字节**。这是移出活动目录并完整保留历史，不代表删除或回收了同等磁盘空间。所有归档项的路径和 SHA-256 均记录在 `archive/v2.0-cleanup-manifest.json`。

`release/V1.x/`、全部源图和提示词均保留。只有上述三张未使用历史源图改变了存放目录。

## 构建与测试简化

- 七套原先重复的测试编译逻辑合并到 `scripts/common.ps1`；不再维护独立测试源码清单。
- `scripts/build.ps1` 与测试共用编译器查找，测试以生产 `build.rsp` 为基础切换入口。
- `scripts/test.ps1` 统一八组回归测试，并支持按需执行 VisualSmoke；旧测试 PS1 简化为一行兼容入口。
- GIF 编码合并到 `scripts/encode_preview.py`，保留真实 WPF 渲染帧，不在编码阶段绘制或重绘素材。
- 测试 EXE、临时 RSP、日志和预览统一生成到 `artifacts/tests/`；源目录不会再次积累这些输出。
- Python 通过参数、环境变量或当前用户依赖环境查找，去除风之翼测试脚本中的固定用户名。
- `scripts/package.ps1` 只打包 EXE 和使用说明，检查目标版本与程序集版本一致，并核对发布 EXE 的 SHA-256 与 ZIP 内容。
- 所有构建与测试 PS1 使用 UTF-8 BOM，确保 Windows PowerShell 5.1 正确读取中文文件名；打包前先解析调用方传入的使用说明路径。
- 测试启动时覆盖本次状态与各组日志，逐组记录 RUNNING/PASS/FAIL，编译失败也会记录，避免误读历史成功结果；PS5.1 和 PS7 的日志统一使用 UTF-8 写入。

## 运行代码与资源整理

- 7 个生产 C# 文件集中到 `src/`，保留各自独立职责。生产、测试都使用更新后的 `build.rsp`。
- 新 `PetAssets` 统一加载角色资源，每次加载角色只打开一次内嵌 ZIP，使用已有角色缓存；图片解码后冻结并关闭流。
- 下攀与反序上攀逐张验证完全相同后，移除 16 张重复 PNG，共 **3,183,141 字节**。运行时两种动作共享冻结位图，省去重复解码和重复图像内存。
- 新增 24 张展翼/滑翔身体帧，共 4,608,809 字节。最终资源包为 **119 项、24,057,521 字节**，包含 116 张独立身体帧及 3 张风之翼。相比 V1.9，95 个共同条目内容逐字节相同。
- 删除不再使用的 `MonitorFromPoint` 声明，以及看点服务内重复的来源列表，统一引用 `HighlightsLayout.Sources`。
- 菜单版本直接读取程序集版本，避免发布后仍显示旧版本号。
- 蝶化渲染只在有待清理状态时执行清理，减少普通角色和滑翔期间每帧重复切换待机图片。
- 默认角色 9 张源图纳入项目 `assets/source/kolo/`；素材构建不再指向用户另一个工程目录。
