验证日期：2026-10-26。程序集和文件版本均为 **2.0.0.0**。

八组生产回归在完整运行中通过。VisualSmoke 的日志局部变量重名导致编译失败，修正后单独重跑通过；此修正未改变生产源码。最终汇总在 `artifacts/v20/final-validation.json`，原始日志在 `artifacts/tests/`。

空中重抓测试使用真实 `MouseButtonEventArgs` 调用 `OnPointerDown → OnTick → OnPointerUp`，逐角色验证静止按住 600ms 不收翼、不重播展翼，以及松手继续下落、地面单击仍可互动。多屏使用坐标与窗口场景测试；WPF 拖放测试调用应用事件处理器，本轮没有操作实体多显示器或模拟系统鼠标拖拽。

## 素材与清理

- 119 个资源条目与加载器完全匹配，无缺失、多余项或 CRC 错误；全部为 512×512 RGBA。
- 95 个沿用资源与 V1.9 逐字节相同；16 个下攀帧与反序上攀帧完全相同，去重减少 3,183,141 字节重复 PNG。
- 新增 24 张展翼滑翔身体帧。源素材、提示词、裁切与肩点配方均保留在 `assets/generated/`。
- 发布 EXE 的内嵌资源 SHA-256 与已验证的 `assets/characters.zip` 一致。
- 280 个历史归档项全部通过 SHA-256 复核，没有删除历史发布。
- PowerShell 脚本通过 PS5.1 与 PS7 语法解析，中文脚本使用 UTF-8 BOM。
