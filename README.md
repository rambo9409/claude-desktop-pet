## 启动与升级

从 [Releases](https://github.com/rambo9409/claude-desktop-pet/releases/latest) 下载 `ClaudeDesktopPet-V2.17.exe`，双击运行；`README-zh-V2.17.txt` 是快捷键与常见问题说明。先退出旧版再启动新版，现有角色和工具设置继续使用。运行需要 Windows 10/11 与 .NET Framework 4.8，不需要 Python、PowerShell 或管理员权限。首次运行若被 SmartScreen 拦截，点“更多信息 → 仍要运行”。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 对话 |
| 左键按住拖动 | 移动角色，可跨显示器 |
| 在空中松开珂洛 | 稳住后从脚下黑色传送门返回当前屏幕底部 |
| 双击珂洛 | 窗口能力剩余冷却减少1分钟 |
| 连续双击珂洛4次（共8次点击） | 主动换装成DeepSeek；每组双击仍减1分钟冷却 |
| 双击GPT6A·龙女 | 开始25分钟龙息专注；计时中显示剩余时间 |
| 双击DeepSeek·小肥鱼 | 打开本地灵感随手记 |
| 拖走珂洛手中的本子 | 让她空出手，恢复窗口魔法资格；仍受开关与冷却约束 |
| 把本子交还珂洛 | 立即暂停窗口魔法 |
| 滚轮、`+`、`-` | 调整角色大小 |
| `0` | 恢复默认大小 |
| 右键 | 角色、移动、工具及设置菜单 |
| Esc | 退出 |

珂洛仅保留慢走，其他角色有慢走和跑步模式。胡桃跑动后化为金蝶；甘雨通过屏幕边、双屏交界与窗口侧边蹬跳，站位不合适时先靠近；瓦雷莎消耗夜魂超快跑，可跑上墙与屏幕顶部，夜魂耗尽后60秒回满。三位原神角色在拖拽和下落时展开风之翼。菜单随角色配色变化。

V2.17为六个角色分别设计字幕气泡：珂洛橙米手账、龙女银紫星纹、小肥鱼蓝白泡泡、胡桃黑红梅花、甘雨蓝白冰晶、瓦雷莎紫粉能量，正文约16px。字幕会跟随角色移动、拖拽、缩放及跨屏，靠近边缘时自动让位；锚点取稳定的角色位置，动作帧不会使文字上下抖动。气泡不抢焦点，也不挡鼠标。详见[字幕样式与跟随](docs/speech-v2.17.md)。

V2.13只重做DeepSeek和龙女各4张跑步图，修正双腿交替及动作衔接，已正确的慢走和其他动作保持。跑步仍按实际移动距离依次播放四帧，不增加额外身体弹跳。详见 [跑步与主动换装](docs/ai-v2.13.md)。

V2.11重做珂洛持本与空手的慢走序列。拖到空中松手后，她会先减速稳住，再通过脚下的黑色传送门回到当前显示器底部，全程约3秒，靠近底部时直接落地。这项演出只由拖拽松手触发；自然走出窗口边缘时沿用普通下落。传送中按住小本本会暂停，松手后继续，再次抓住角色则取消。

珂洛累计可见使用满3分钟后，必定摘换发饰、借布料遮挡换装成为现有蓝发鱼尾DeepSeek。移动和安静模式都计时，隐藏和最小化暂停；到点时若在拖拽、传送或操作菜单，会在安全结束后补触发。切换到其他角色再回来重新计时，右键可关闭自动彩蛋。

也可在她的头部或身体连续双击4组，共8次点击，组间不超过1.5秒，主动开始同一换装动画；触发前不要点到小本本。前3组显示1/4、2/4、3/4进度，每组仍减1分钟冷却；第8次松手在有支撑时立即显示换装第一帧，空中或传送中则等落稳。即使自动彩蛋关闭，手动手势仍可用。

V2.16将珂洛换装加快1.5倍，整段从4.8秒缩短至约3.2秒，8个阶段每个约0.4秒；自动和主动触发共用此节奏。详见[换装加速说明](docs/costume-speed-v2.16.md)。

V2.14修复了“超过8次点击反而没反应”：现在触发后继续普通点击不会中断，也不再重复扣冷却。按住后真正拖动超过5px，或打开菜单、隐藏、最小化、切换角色，仍可取消手动请求。触发前的拖拽、超时、多余不成对单击、本子操作与跨角色仍重置计数。详见[连续点击修复](docs/ai-v2.14.md)。

珂洛的“窗口魔法”会随机缩小或拉近一个普通应用窗口，成功冷却5分钟。右键有独立开关：新安装默认关闭；已有窗口能力冷却存档的升级用户保持原先启用状态。关闭立即取消施法，双击扣冷却不会自动打开开关。

V2.9中珂洛默认拿着本子，此时不对窗口施法。把本子拖离、再拖回或归还可以切换她的忙碌状态；隐藏、换形象和重启会回收本子。小肥鱼按用户参考重绘为蓝发鲸尾女仆少女，保留本地随手记。详见 [小本本与参考形象](docs/notebook-v2.9.md)。

GPT6A·龙女在V2.12以珂洛和DeepSeek为画风参考重绘27张运行素材，统一Q版比例、立体发束、眼睛高光和服装层次；保留白银发、淡紫眼、短龙角、蝠翼、卷尾和白紫裙装。全套动作和工具头像同步更新，详见 [V2.12说明](docs/ai-v2.12.md)。

GPT6A的右键能力菜单可选择15、25或45分钟专注，星环显示进度，到时提醒；切换角色、隐藏或退出会取消。DeepSeek的随手记复用其他工具窗口的浅蓝白主题、渐变标题与圆角卡片，可保存和回看灵感记录，保存后有泡泡反馈。两者是本地宠物功能，无需模型API或账号，详见 [AI伙伴说明](docs/ai-companions-v2.8.md)。

## 战斗循环助手

右键 → 工具 → 战斗循环助手。

1. 先设置“我的角色”，搜索并勾选自己拥有的角色。名单缺少新角色时可以手动添加；旅行者各元素形态分别勾选。
2. 按已拥有角色筛选参考队伍。资料库目前收录14套，包括当期攻略和胡桃双水、甘雨融化、砂糖武装、纳行久双水等经典队；可查看缺少谁，但不能将缺员队当作可用队载入。
3. 载入完整队伍，或手动填写四人面板、技能总倍率、冷却与驻场时间；也可导入 PNG/JPG/BMP 面板截图或粘贴剪贴板截图。
4. 截图由 Windows 本机文字识别提取，先核对预览，再应用到当前角色，所有字段都能继续手改。截图不会上传到外部服务。
5. 生成后查看手法说明、通用参考属性线，以及模型支持时的当前与达标后伤害。拥有角色不等于满足命座、武器和充能条件，仍需核对卡片说明。

新版本角色不需要换一套工具：手动输入和本机OCR仍可用，已拥有名单也可扩充。有核验来源的新配队可通过导入资料库JSON更新，无需重新编译程序；遇到通用公式不支持的新机制，只提供手法，伤害模型需要单独升级。资料显示核对日期、适用版本、来源和手法依据，不自动联网获取攻略。具体更新格式见[角色拥有表与资料更新](docs/roster-updates-v2.7.md)。

筛选只从已收录的完整攻略中匹配，未命中不代表这些角色无法组队，也不会自动把新角色塞进旧队并沿用原手法。基础名单是有来源的名称快照，未保证未来版本全角色实时完整。

伤害为通用粗算：持续增益按覆盖折算，短冷却 E 在时间允许时补放；不完整模拟逐帧操作、精确产球、装备被动、命座、月反应和其他角色专属机制。“通用参考线”不等于某个角色的毕业面板，特殊队伍的真实排名请结合来源与游戏实测。详情见[战斗助手说明](docs/combat-planner-v2.6.md)。

## 数据与问题排查

设置、战斗存档和缓存位于 `%LocalAppData%\KoloPet`。重要文本设置使用临时文件替换，写入失败保留旧文件；损坏的战斗存档先备份为 `.broken-…json`。存储与可恢复异常写入 `diagnostics.log`，未处理异常写入 `error.log`。

OCR 不可用时仍能手动填写。可在 Windows“设置 → 时间和语言 → 语言”安装中文或英文的光学字符识别组件。识别结果可能有错字和数字误读，请核对后再应用。

## 从源码构建

需要 .NET Framework 4.8 Developer Pack 和 Windows 10/11 SDK，脚本会自动寻找引用程序集。保持 C# 5 兼容，不需要 .NET SDK。

```powershell
.\build.cmd
.\test.cmd -SkipPreviews -IncludeVisualSmoke
.\package.cmd -Version 2.17 -InstructionsPath .\docs\usage-v2.17.txt
```

CMD 包装只为当前 PowerShell 进程指定执行策略，不修改系统策略。默认测试21组，加 `-IncludeVisualSmoke` 共22组。`-SkipPreviews` 只跳过 GIF 编码，仍运行渲染与断言测试。重建素材或编码 GIF 才需 Python、Pillow、NumPy；通过 `-Python`、`KOLO_PYTHON`、PATH 或 `py` 查找。
