# 原神启动 V2.5

多形象 Windows 桌宠，原名“珂洛桌宠”。
内置珂洛、胡桃、甘雨和瓦雷莎四套形象。
每套形象都有待机、互动、慢走和跑步动作。珂洛、胡桃、瓦雷莎保留攀爬，甘雨改为蹬墙跳。
慢走、跑步、上攀各四帧，下攀复用上攀帧并反向播放；另有甘雨跳跃四帧、胡桃人形跑步四帧，以及三位原神角色各八帧的展翼滑翔动作。珂洛新增四帧举手施法姿势。资源包共120张角色帧和3张风之翼。
瓦雷莎奔跑时戴上面具、双腿高速旋转，跑速是其他角色的四倍（V2.0 的两倍），可以直接跑上墙面、沿屏幕顶部倒挂奔跑，并连贯地经过转角；慢走保持正常形态。
瓦雷莎的夜魂条按实际超快跑距离消耗，满条以当前显示器从左下沿墙到顶部中间的路线校准。耗尽后锁定超快跑，离开超快跑时逐渐恢复，空条回满需要60秒；锁定期间仍能普通走路和跑步。半空耗尽会直接展翼滑翔。
珂洛的新造型融合参考图右侧角色的橙色长发、金花、黑蝴蝶结、米白裙和黑色束腰，所有移动动作与举手能力使用同一套造型。她会随机把一个普通应用窗口缩小至约65%尺寸，或拉到身边；先举手再施法，手心出现旋转金色法阵，牵引线连接目标窗口，金色描边和前后位置虚线显示变化。优先选择当前屏幕有可见区域的窗口，跨屏目标会拉回身边。实际位置或大小改变才提示成功，成功冷却5分钟；窗口拒绝变化时提示失败，15秒后重试。首次可用前等待20秒，安静模式、隐藏和拖拽期间暂停施法。冷却跨角色切换和重启保存。
双击珂洛可减少1分钟剩余冷却，多次双击可以减至就绪，并显示剩余时间。拖拽不算双击，就绪时不会储存额外减免；调整后的冷却会立即保存。其他角色保持原有单击对话和拖拽行为。
胡桃先使用原有人形跑步动作起步，再一边跑动一边由脚部向帽子逐渐化为金色碎光与小蝴蝶，聚成主蝶；停下或互动时反向恢复人形。过渡过程中改变动作会连续反转。
胡桃、甘雨和瓦雷莎在拖拽和下落时依次抬臂展翼、屈腿滑翔、收翼落地，分别配黑红暗金、蓝白、紫粉风之翼。每人八个身体姿势与左右双翼围绕肩点同步展开，滑翔时轻微摆动，落地时收翼并缓冲。V2.2 稳定下落速度为默认大小下约88逻辑像素/秒，甩出后翅膀会限制速度并逐渐减小水平漂移。拖拽转下落保持同一段动作，切换角色、互动或其他移动动作会清理滑翔状态。珂洛没有风之翼。
动作随移动距离连续推进，变速不跳帧；攀爬时手部贴合边缘。
胡桃重绘为与甘雨、瓦雷莎一致的圆润 Q 版画风，帽子采用完整绘制的材质与阴影。
胡桃慢走保持左右腿交替；甘雨改为双脚贴地的小步前后交替，取消抬脚和高抬膝。两人的各帧以头部位置对齐，甘雨慢走配色与待机、跑步统一。
甘雨可以在屏幕侧边、双屏交界和窗口侧边之间借力上升，也能从同一面窗口侧边向外蹬出、转身返回更高位置，最终落在窗口顶部。跳跃包含接触压腿、蹬离、腾空与落地姿势；附近窗口之间可直接短跳，不再要求先来回碰壁两次。当前位置不适合起跳时，会先沿当前可站立区域小跑靠近，再重新确认路线。双屏交界仅在两块屏幕共同可见的高度内提供借力，同高底边可连续走过，底边不同高时通过跳跃跨越。所有弧线仍检查可见桌面、窗口遮挡和落脚空间；靠近途中目标失效会停下，半空路线失效则展开风之翼缓降。
互动文字保持清晰字号，每条文字首次出现时贴近角色头顶定位，在这条文字消失前固定屏幕位置，避免随姿势和移动抖动；下一条重新定位。
支持拖到其他显示器，保留鼠标抓取位置，并在松手所在屏幕落地。
安静模式可减少自动跑动。

## 启动

解压 `release/V2.5/原神启动-V2.5.zip`，双击 `原神启动.exe`。程序已内嵌全部角色素材，运行包只包含 EXE 和使用说明。工程根目录的 `原神启动.exe` 是同一构建。升级时先退出旧版，原有角色、冷却和看点布局设置继续使用。

## 操作

- 左键点击：和她说话
- 双击珂洛：施法剩余冷却减少1分钟
- 左键拖动：按住角色移动，可跨显示器
- 鼠标滚轮：改变大小
- `+`：放大
- `-`：缩小
- `0`：恢复默认大小
- 右键：打开功能菜单
- Esc：退出

## 右键菜单

- 选择形象：珂洛、胡桃、甘雨、瓦雷莎
- 工具 → 每日看点：打开资讯汇总
- 工具 → GPT 重置预测：同步堂云 AI 的公开预测
- 安静模式：每 35 至 75 秒短走一次
- 自动移动：关闭后不再自动开始行走或跑步，仍可手动触发
- 移动模式：慢速行走、活力奔跑、走跑交替，默认慢速行走；选择自动保存
- 动作与大小：慢慢走一会儿、立即跑步、调整大小

胡桃对应的“立即跑步”显示为“化蝶飞行一会儿”，移动模式显示“金蝶飞行”和“走飞交替”。
甘雨右键有“蹬墙跳上附近窗口”。可直接起跳，也会先小跑到附近的可起跳位置；无需事先把她拖到屏幕外侧。自动移动开启且非安静模式时，也会在双屏中间寻找借力路线；只有一面窗口侧边时可连续蹬跳。目标仍需要可见的落脚位置，没有安全路线时会提示或折返。

默认大小下，慢走速度为 30–45 逻辑像素/秒，普通跑步 95–140，瓦雷莎有夜魂时跑步 380–560，耗尽恢复期间回到普通跑步速度与正常形象。
角色缩放后速度同比例调整；安静模式减少活动频率，不改变速度倍率。
菜单随角色切换配色：珂洛橙金、胡桃黑红、甘雨蓝白、瓦雷莎紫粉。
右键菜单已移除互动分区及其四项操作；左键单击仍可对话。

## 每日看点

窗口与角色菜单使用同一套配色，带当前角色头像、今日速览、固定分类导航、来源分区、排行卡片、圆角按钮和主题滚动条。切换角色时，已打开的窗口也会更新主题。点击顶部分类可展开并跳转到对应版块。

程序会在后台自动更新。
默认每六小时检查一次。
当天三小时内的结果会直接复用。

内容包括：

- B站热门视频
- 微博热搜
- 今日体育新闻
- NBA 新闻（虎扑）
- GitHub 热门 Fork：近90天创建的公开原创项目，按累计 Fork 排序，附 Star 数和语言
- AI、股票、汽车、游戏资讯
- 美女·时尚：女星、时尚和写真相关资讯

结果会生成一句总览和分区卡片。
点击“打开”可查看原页面。
点击版块标题可以折叠或展开，拖动标题旁的手柄可上下排序。
折叠状态和排序会自动保存，重新打开后仍然保留。
每个来源分别显示更新时间和状态；源站不可用时保留该栏最近7天内的缓存并明确标注。新闻检索过滤超过7天的旧文。数据缓存位于 `%LocalAppData%\KoloPet`。

## GPT 重置预测

右键 → 工具 → GPT 重置预测。窗口通过 [tangyun.ai](https://tangyun.ai/) 的公开接口同步，显示未来24/48小时概率、上次重置、历史常见时段、间隔图和历史记录，沿用当前角色配色。

打开后异步获取，每10分钟自动刷新，也可以手动刷新或打开原站。时间统一为北京时间。来源提供明确截止时间和信号时才显示倒计时；未提供时明确提示。接口失败保留上次数据并提示，超过20分钟未更新的预测标记为过期。

这是第三方的全站重置观察，不是个人账号额度查询，也不是确定会发生的重置承诺。来源和接入说明见 `docs/gpt-reset-data-source.md`。

## 联网与安全

每日看点和重置预测只访问公开网页和公开接口。
程序不会读取浏览器登录、Cookie 或账号密码。
程序不会上传个人文件。
程序不用 PowerShell，也不用管理员权限。
关闭工具窗口不影响桌宠动作。

## 角色说明

新增角色是桌宠用同人风格形象。
仅建议个人使用，不要用于商用分发。

## 构建与验证

生产源码集中在 `src/`，`build.rsp` 是生产和测试共用的唯一编译清单。当前角色源图位于 `assets/generated/`，旧版珂洛源图保存在 `assets/source/kolo/`，从源码重建不依赖其他工程。

```powershell
# 使用现有内嵌素材构建
& ./scripts/build.ps1
# 重新裁切源图、生成素材并构建（需要 Python、Pillow、NumPy）
& ./scripts/build.ps1 -RebuildAssets
# 执行十五组回归测试并生成 WPF 动画预览
& ./scripts/test.ps1
# 看点窗口的折叠、排序与重新打开检查
& ./scripts/test.ps1 -Suite VisualSmoke
# 生成精简运行包
& ./scripts/package.ps1 -Version 2.5 -InstructionsPath ./docs/usage-v2.5.txt
```

编译需要 Windows 的 .NET Framework C# 编译器和 .NET Framework 4.8 引用程序集。运行 EXE 不需要 Python 或 PowerShell。

十五组回归包括跨屏移动、蝶化、走跑节奏、菜单主题、动作播放、文字布局、展翼、看点解析、缓降物理、夜魂耗尽与恢复、窗口能力与冷却、重置预测，以及双击输入、甘雨蹬跳路径和新增的双屏回归。双屏回归覆盖实际两屏不同底边、负坐标、不同 DPI、单墙连续蹬跳、先靠近再起跳和动态取消。窗口能力测试使用模拟窗口和测试自己创建的辅助窗口，验证实际 Win32 缩小、牵引及焦点，不修改用户正在使用的窗口。日志、测试 EXE、WPF 渲染帧统一放在 `artifacts/tests/`，每次运行会重新记录状态。单独运行 VisualSmoke 验证看点窗口布局，合计16组。历史预览保留在对应 `release/V*/previews/` 目录。

素材由内置 imagegen 生成，裁切与装配脚本使用原始透明图。V2.0 的三套八帧源图为 `assets/generated/{hutao,ganyu,varesa}-glide-v20.png`，完整提示词和参考来源见 `assets/generated/glide-v20-prompts.md`；逐帧肩点、统一缩放和落地对齐参数见 `assets/generated/glide-v20-crops.json`。动作参考[原神官方滑翔演示](https://genshin.hoyoverse.com/en/news/detail/7154)，按现有 Q 版画风重新绘制。

目录说明见 `docs/project-layout.md`；冗余文件归档、资源去重和脚本合并记录见 `docs/cleanup-v2.0.md`。历史发布和源图保留，已退出构建的入口及测试产物移入 `archive/`，逐项保存 SHA-256 清单。

本次发布验证与文件校验和见 [V2.5 发布验证](docs/validation-v2.5.md)。珂洛素材使用内置 imagegen 生成，提示词见 `assets/generated/kolo-v22-prompts.md`。V2.5 沿用现有角色帧，新增双屏与单墙蹬跳路线，姿态由动作时序与 WPF 变换实现。
