# 原神启动 V2.10

Windows 桌宠与小工具，内置珂洛、GPT6A·龙女、DeepSeek·小肥鱼，以及胡桃、甘雨、瓦雷莎六套 Q 版形象。原名“珂洛桌宠”。

## 启动与升级

解压 `release/V2.10/原神启动-V2.10.zip`，双击 `原神启动.exe`。先退出旧版再启动新版，设置和缓存会继续使用。运行需要 Windows 10/11 与 .NET Framework 4.8，不需要 Python、PowerShell 或管理员权限。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 对话 |
| 左键按住拖动 | 移动角色，可跨显示器 |
| 双击珂洛 | 窗口能力剩余冷却减少1分钟 |
| 双击GPT6A·龙女 | 开始25分钟龙息专注；计时中显示剩余时间 |
| 双击DeepSeek·小肥鱼 | 打开本地灵感随手记 |
| 拖走珂洛手中的本子 | 让她空出手，恢复窗口魔法资格；仍受开关与冷却约束 |
| 把本子交还珂洛 | 立即暂停窗口魔法 |
| 滚轮、`+`、`-` | 调整角色大小 |
| `0` | 恢复默认大小 |
| 右键 | 角色、移动、工具及设置菜单 |
| Esc | 退出 |

角色有慢走和跑步模式。胡桃跑动后化为金蝶；甘雨通过屏幕边、双屏交界与窗口侧边蹬跳，站位不合适时先靠近；瓦雷莎消耗夜魂超快跑，可跑上墙与屏幕顶部，夜魂耗尽后60秒回满。三位原神角色在拖拽和下落时展开风之翼。菜单随角色配色变化，互动文字出现后固定位置。

珂洛的“窗口魔法”会随机缩小或拉近一个普通应用窗口，成功冷却5分钟。右键有独立开关：新安装默认关闭；已有窗口能力冷却存档的升级用户保持原先启用状态。关闭立即取消施法，双击扣冷却不会自动打开开关。

V2.9中珂洛默认拿着本子，此时不对窗口施法。把本子拖离、再拖回或归还可以切换她的忙碌状态；隐藏、换形象和重启会回收本子。小肥鱼按用户参考重绘为蓝发鲸尾女仆少女，保留本地随手记。详见 [小本本与参考形象](docs/notebook-v2.9.md)。

GPT6A·龙女在V2.10按用户参考重绘为白银发、浅紫眼、短龙角、蝠翼和卷尾的Q版少女，配白紫裙装。待机、慢走、跑步、攀爬、施法、拖拽和下落采用同一套形象，菜单与龙息专注显示同步为紫白配色，详见 [龙女参考形象](docs/dragon-v2.10.md)。

GPT6A的右键能力菜单可选择15、25或45分钟专注，星环显示进度，到时提醒；切换角色、隐藏或退出会取消。DeepSeek可保存和回看灵感记录，保存后有泡泡反馈。两者是本地宠物功能，无需模型API或账号，详见 [AI伙伴说明](docs/ai-companions-v2.8.md)。

## 战斗循环助手

右键 → 工具 → 战斗循环助手。

1. 先设置“我的角色”，搜索并勾选自己拥有的角色。名单缺少新角色时可以手动添加；旅行者各元素形态分别勾选。
2. 按已拥有角色筛选参考队伍。资料库目前收录14套，包括当期攻略和胡桃双水、甘雨融化、砂糖武装、纳行久双水等经典队；可查看缺少谁，但不能将缺员队当作可用队载入。
3. 载入完整队伍，或手动填写四人面板、技能总倍率、冷却与驻场时间；也可导入 PNG/JPG/BMP 面板截图或粘贴剪贴板截图。
4. 截图由 Windows 本机文字识别提取，先核对预览，再应用到当前角色，所有字段都能继续手改。截图不会上传到外部服务。
5. 生成后查看手法说明、通用参考属性线，以及模型支持时的当前与达标后伤害。拥有角色不等于满足命座、武器和充能条件，仍需核对卡片说明。

新版本角色不需要换一套工具：手动输入和本机OCR仍可用，已拥有名单也可扩充。有核验来源的新配队可通过导入资料库JSON更新，无需重新编译程序；遇到通用公式不支持的新机制，只提供手法，伤害模型需要单独升级。资料显示核对日期、适用版本、来源和手法依据，不自动联网获取攻略。具体更新格式见[角色拥有表与资料更新](docs/roster-updates-v2.7.md)。

筛选只从已收录的完整攻略中匹配，未命中不代表这些角色无法组队，也不会自动把新角色塞进旧队并沿用原手法。基础名单是有来源的名称快照，未保证未来版本全角色实时完整。

伤害为通用粗算：持续增益按覆盖折算，短冷却 E 在时间允许时补放；不完整模拟逐帧操作、精确产球、装备被动、命座、月反应和其他角色专属机制。“通用参考线”不等于某个角色的毕业面板，特殊队伍的真实排名请结合来源与游戏实测。详情见[战斗助手说明](docs/combat-planner-v2.6.md)。

## 其他工具

- **每日看点**：微博、B站、体育、虎扑NBA、GitHub热门Fork，以及AI、股票、汽车、游戏、美女·时尚。版块可折叠和拖拽排序，布局自动保存，失败会标注缓存。
- **GPT重置预测**：同步 [tangyun.ai](https://tangyun.ai/) 的公开全站预测，每10分钟更新。它不是个人额度查询，概率不保证发生。详见[数据源说明](docs/gpt-reset-data-source.md)。

工具不读取游戏内存，不修改游戏文件，不自动按键。资讯功能只访问公开来源；不会读取账号密码、Cookie 或上传个人文件。

## 数据与问题排查

设置、战斗存档和缓存位于 `%LocalAppData%\KoloPet`。重要文本设置使用临时文件替换，写入失败保留旧文件；损坏的战斗存档先备份为 `.broken-…json`。存储与可恢复异常写入 `diagnostics.log`，未处理异常写入 `error.log`。

OCR 不可用时仍能手动填写。可在 Windows“设置 → 时间和语言 → 语言”安装中文或英文的光学字符识别组件。识别结果可能有错字和数字误读，请核对后再应用。

## 从源码构建

需要 .NET Framework 4.8 Developer Pack 和 Windows 10/11 SDK，脚本会自动寻找引用程序集。保持 C# 5 兼容，不需要 .NET SDK。

```powershell
.\build.cmd
.\test.cmd -SkipPreviews -IncludeVisualSmoke
.\package.cmd -Version 2.10 -InstructionsPath .\docs\usage-v2.10.txt
```

CMD 包装只为当前 PowerShell 进程指定执行策略，不修改系统策略。默认测试20组，加 `-IncludeVisualSmoke` 共21组。`-SkipPreviews` 只跳过 GIF 编码，仍运行渲染与断言测试。重建素材或编码 GIF 才需 Python、Pillow、NumPy；通过 `-Python`、`KOLO_PYTHON`、PATH 或 `py` 查找。
